# Spin the Wheel — GitHub Pages

This is the uploaded standalone HTML wheel, prepared for GitHub Pages. The editor-only SDK/bootstrap references have been removed; the page uses Tailwind CSS and Lucide from public CDNs.

## Publish
1. Create a **public** repository on GitHub (for example `spin-the-wheel`).
2. Upload `index.html` to the repository root (same level as this README).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for the Pages deployment, then open the URL shown in Settings → Pages.

## Notes
- The page currently starts with sample names and lets visitors add/remove names in their own browser session.
- It is a standalone name-picker wheel, not the later QR registration / question-bank / admin-dashboard application.
- GitHub Pages hosts static files only; it does not provide shared storage or server-side logic.
